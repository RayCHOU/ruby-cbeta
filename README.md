# ruby-cbeta

Ruby gem for use CBETA resources

* Convert CBETA XML P5a to Text
* Convert CBETA BM to Text
* Check CBETA XML P5a
* Access CBETA gaiji (missing character) database

## Reqirements

### nokogiri

    gem install nokogiri

## Getting Started

    gem install cbeta
